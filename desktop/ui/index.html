What happens next: a terminal window opens and runs agy in an empty sign-in folder (the account you are signed in to elsewhere is not used). agy does not open the browser by itself here:

1. Choose 1. Google OAuth and press Enter. 2. Open the URL it prints and sign in with the account for this profile. 3. Copy the code Google shows and paste it into the terminal. This window notices the sign-in by itself; then type /exit in the terminal.

Using an existing profile name signs that profile in again; it is only replaced once the new sign-in succeeds.
